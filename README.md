# Jumbo-Pro-Calculator
A multi-functional calculator application developed in Python using Tkinter, supporting basic operations, scientific calculations, and advanced features with an interactive GUI.
## Features
• Basic arithmetic operations (Addition, Subtraction, Multiplication, Division)  
• User-friendly Graphical User Interface (GUI) using Tkinter  
• Real-time input and result display  
• Clear (C) and Clear Entry (CE) functionality  
• Error handling for invalid inputs  
• Multiple calculator versions for different user needs  

### Advanced Features
• Scientific functions (sin, cos, tan, log, ln, π, e)  
• Power and root calculations (x², x³, √)  
• Factorial and percentage operations  
• Memory functions (MC, MR, M+, M-)  
• Degree and Radian mode support  
• Graph plotting functionality (Matplotlib integration)  
• Modern and interactive UI design  
• Converter functionality for extended usability  

#### Technologies Used
