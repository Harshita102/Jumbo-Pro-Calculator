# Jumbo-Pro-Calculator
A multi-functional calculator application developed in Python using Tkinter, supporting basic operations, scientific calculations, and advanced features with an interactive GUI.
## Features
- Basic calculations (+, -, *, /)
- Scientific functions (sin, cos, log, etc.)
- Advanced calculator UI
- Graph plotting (if added)
- User-friendly interface

## Technologies Used
- Python
- Tkinter
- Matplotlib

## How to Run
1. Install Python
2. Run any file:
   python calculator.py
